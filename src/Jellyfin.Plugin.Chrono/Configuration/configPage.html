Universes

Add a universe

Build a universe from Wikidata (titles that belong to a franchise, in release order), a TMDB collection in your library, or a ranked MDBList/Trakt list (custom order, e.g. a chronological list). Combine several sources: the first ranked list becomes the main timeline.

Type a franchise name (e.g. "Middle-earth", "Wizarding World") and press Enter.

Requests (Seerr / Jellyseerr)

Settings → General → API Key in Seerr. Requests are made on behalf of the matching Seerr user (linked Jellyfin account); otherwise as the API key owner.

Playlists

Generated playlists are public; Jellyfin still requires an owner.

Advanced

Curated universe registries. Universes from later registries win when their revision is newer. The plugin also ships a bundled copy of the default registry. Local universe files can be placed in the plugin's data folder under universes/*.json.
